Where do I find the passcode?

  1. On your Mac, click the Synapse icon in the menu bar.
  2. Choose Show Passcode (TOTP).
  3. Type those 6 digits above before the code rotates.
📶 Your phone and Mac must be on the same Wi-Fi network. Nothing here reaches the internet.
